# Langit Launcher

Launcher Android gaya iOS 18 untuk Honor 200 dan Samsung A16.

- Widget Jam dan Cuaca (Open-Meteo, tiada API key)
- Ikon bentuk squircle 4 lajur, badge merah notifikasi
- Pil Cari, leret ke bawah untuk cari, dok kaca kabur
- Mod edit (ikon bergoyang, seret, tambah halaman), Sesuaikan (saiz, Gelap, Warna, wallpaper)
- Pustaka Apl (halaman paling kanan) dengan kumpulan kategori

APK terkini: tab **Releases**. Dibina automatik oleh GitHub Actions setiap kali `main` dikemas kini.
